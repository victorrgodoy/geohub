# Imagens dos Continentes

## 📸 Nomenclatura dos Arquivos

Salve as imagens com os seguintes nomes (exatamente como mostrado):

- `africa.jpg` ✅
- `europe.jpg` ✅
- `asia.jpg` ✅
- `americas.jpg` ✅
- `oceania.jpg` ✅
- `antartica.jpg` ✅ (sem "c" mesmo)

## 📐 Especificações Recomendadas

- **Formato**: JPG ou PNG
- **Resolução mínima**: 1200x800px
- **Orientação**: Landscape (horizontal)
- **Tamanho do arquivo**: Menor que 500KB (para performance)

## ✨ Efeitos Aplicados

Ao adicionar as imagens, você verá:
- ✅ Opacidade de 20% (sobe para 25% no hover)
- ✅ Zoom suave no hover
- ✅ Gradiente overlay para manter legibilidade
- ✅ Fallback automático se a imagem não existir
